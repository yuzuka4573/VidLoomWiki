# アカウントの種類について
ちょっと使用が異なるアカウントの種類について解説

## アカウントのプラン
VidLoomにはいくつかのプランがあります  
- Starter
    無料で使えるプラン  
    基本的な機能のみが使える  
    動画の生成予約枠: *1枠*  
    月に使えるポイント数は **100pts**  
    無料で使えるアセット容量 **100MB**  
  
- Plus
    現状FanBoxで支援すると付与されるプラン  
    フォントのアップロード（3枠分）が使用できます  
    動画の生成予約枠: *3枠*    
    月に使えるポイント数は **300pts**   
    無料で使えるアセット容量 **500MB**   
  
- Premium
    現状FanBoxで一定額以上支援すると付与されるプラン  
    Plusで解禁された機能に加えてLocalTTS連携機能(単体機能/台本管理内で使える機能),
    **Webブラウザを使ったローカルレンダリング**がアンロックされる
    フォントのアップロード数が5枠に増量  
    動画の生成予約枠: *5枠*    
    月に使えるポイント数は **500pts**
    無料で使えるアセット容量 **1000MB**  
  
- Pro
    現状FanBoxで一定額以上支援すると付与されるプラン  
    基本Premiumまで解禁されている機能に加えて、**アプリを使ったローカルレンダリング機能**も解放  
    動画の生成予約枠: *5枠*    
    フォントのアップロード数が10枠に増量  
    極稀に新規機能を使える*かも*しれない
    月に使えるポイント数は **1000pts**
    無料で使えるアセット容量 **5000MB**   

## pts(ポイント)について
ptsは素材のアップロード、動画生成などあらゆるところで使うもの  
回復は月の最初か、管理者の気分でボーナスptsとして付与されたりする  
なお上限はアセットのアップロード容量や、生成済み動画の履歴の残り具合で*減って*いきます  
最大限のポイントを獲得しておきたいなら、ちゃんとキレイに使おうってことです  
(そのほうがサーバーのストレージを消費しないので非常にありがたい)  

## 動画の生成予約枠について
プランによって生成予約枠に制限がかかっています  
これは本番生成、プレビュー生成を何個まで予約できるかというものです  
生成順番は変わりませんが、同時に動画を作ってたりする場合、この枠が多いと何かと便利です  
なおこの枠は、動画が生成完了したときと、ユーザーがキャンセルした場合に返還されます 
どうしても待ち時間ゼロで使いたい!って方は、上位プラン(Premium / Proプラン)にすると強力なローカルレンダリングが使えます
