# アセットのアップロード
VidLoomを使う上で絶対に必要な素材のアップロードとかの解説

![アセット画面](./image/assetMainPage.webp)

## アップロード可能素材について
VidLoomではいろんな素材をアップロードできます
- 画像
    - jpeg
    - png
    - gif
    - webP

- 音声
    - mp3
    - mp4
    - wav
    - ogg
  
- フォント
    - ttf
    - otf
    - woff  
  
  ※ 動画には**現状対応してません**
  ## アップロード方法
  - 画像、音声の場合
  登録画面が"アセット"となってることを確認して、画面中央か右上にある"ファイルをアップロード"ボタンを押す    

![登録画面](./image/assetUploader.webp)

ファイルを選択を押して、アップロードしたいものを選択する(複数選択可能)  
ファイル個別に対して、自分で名前を決めたり、複数ファイルにタグ付け、説明の追加もできる  

![ファイルの設定](./image/fileConf.webp)

アップロードできたら表示されてるはず  

![ファイルアップロード後](./image/fileUploaded.webp)

  - フォントの場合  
<font color="Red">※注意※ 有料フォントを使うのはいいけど、ちゃんとライセンスを買うこと。あと基本商業利用可能なものを使うこと。ここらへんのトラブルには管理者は一切関与しません</font>  
登録画面が"アセット"となってることを確認して、画面中央か右上にある"ファイルをアップロード"ボタンを押す    

![フォント登録画面](./image/assetsFontMain.webp)

フォントがアップロードされると速やかに利用可能フォントに加えられます  

![アップロード済みフォント](./image/fontUploaded.webp)

ちなみに「利用可能なフォント」一覧で□になってるフォントがあれば*日本語非対応フォント*になってます
