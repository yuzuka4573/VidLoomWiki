# VidLoomとは
読み方: びっとるーむ
あなたの動画を作る手助けをする機織り機  
動画以外の素材、決められた素材の配置テンプレート、キャラクターの設定をすることで、動画が作れるWebサービスです  
  
## 推奨環境
PC (Windows,MacOS,Linux)で動くWebブラウザ  
現状はChromeとFirefoxで動作確認が取れている  
  
## 対応素材
VidLoomでは以下の多彩な素材フォーマットに対応しています。

- **画像**:
    - **PNG** (`.png`, `.apng`)
    - **JPEG / JPG** (`.jpeg`, `.jpg`)
    - **GIF** (`.gif`) - *アニメーションGIF対応（動画内での自動ループ再生対応）*
    - **WebP** (`.webp`)
    - **SVG** (`.svg`)
    - **BMP / ICO / AVIF** (`.bmp`, `.ico`, `.avif`)
  
- **音声**:
    - **MP3** (`.mp3`)
    - **WAV** (`.wav`)
    - **OGG** (`.ogg`)
    - **M4A / AAC** (`.m4a`, `.aac`)
    - **MP4音声** (`.mp4`)
  
- **フォント**:
    - **TTF** (`.ttf`)
    - **OTF** (`.otf`)
    - **WOFF / WOFF2** (`.woff`, `.woff2`)
  
## 便利機能
- LocalTTS連携
VoiceVoxとAivisSpeechがPCにインストールされていれば、アプリケーションを実行した状態で、VidLoomを操作していると台本の音声生成時に連携して自動で音声をつくる機能が使えます  
(キャラクター設定で事前に音声の設定をする必要があります)  

- 読み自動生成機能
LocalTTSが正確に文章を読めるようにする読み設定を自動で対応することができます  
読み方には標準的な読みを推論するシステムと、ユーザーが登録した単語を使用する個人辞書、他のユーザーが共有してくれた共有辞書の3つを使用します  

- 単語登録機能
今どきの言葉や英語、特殊すぎる読み方をする単語の読みを登録できる機能  
辞書に登録した読みは読み自動生成機能を使ったときに参照されます  
また、自分専用の辞書と共有辞書が存在しており、共有辞書はほかのユーザーと共有することができます  

- AI文字起こし
音声素材から文字を書き出せる機能です。すべての処理はローカルで実行されるので、音声がサーバーに残る心配はありません。  
ただし、その関係上Webブラウザに文字起こし用のモデルのダウンロードや重い処理がかかるので、安定度、品質ともにちょっと低め  
  
- ローカルレンダリング (Web版 / アプリ版)  
上位プランで使うことができる強力な動画生成手段  
サーバーでのレンダリングで発生する待ち時間を限りなく減らすことができる  
追加のポイントを支払うことになるが、自前のPCパワーを存分に活用できる
