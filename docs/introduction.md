# VidLoomとは
読み方: びっとるーむ
あなたの動画を作る手助けをする機織り機  
動画以外の素材、決められた素材の配置テンプレート、キャラクターの設定をすることで、動画が作れるWebサービスです  
  
## 推奨環境
PC (Windows,MacOS,Linux)で動くWebブラウザ  
現状はChromeとFirefoxで動作確認が取れている  
  
## 対応素材
- 画像
    - jpeg
    - png
    - gif
  
- 音声
    - mp3
    - mp4
    - wav
    - ogg
  
- フォント
    - ttf
    - otf
    - woff
  
## 便利機能
- LocalTTS連携
VoiceVoxとAivisSpeechがPCにインストールされていれば、アプリケーションを実行した状態で、VidLoomを操作していると台本の音声生成時に連携して自動で音声をつくる機能が使えます  
(キャラクター設定で事前に音声の設定をする必要があります)  

- AI文字起こし
音声素材から文字を書き出せる機能です。すべての処理はローカルで実行されるので、音声がサーバーに残る心配はありません。  
ただし、その関係上Webブラウザに文字起こし用のモデルのダウンロードや重い処理がかかるので、安定度、品質ともにちょっと低め  
  
- ローカルレンダリング (Web版 / アプリ版)  
上位プランで使うことができる強力な動画生成手段  
サーバーでのレンダリングで発生する待ち時間を限りなく減らすことができる  
追加のポイントを支払うことになるが、自前のPCパワーを存分に活用できる
